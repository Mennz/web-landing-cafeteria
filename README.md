# Café Aroma

Landing page de uma cafeteria fictícia, com cabeçalho e menu, seção de
destaque, cardápio em cards, seção sobre e rodapé com contato. HTML e CSS
puro, sem framework.

## O que pratiquei

- Estrutura semântica com `header`, `main`, `section` e `footer`
- Flexbox pra alinhar menu, cards e o rodapé
- Âncoras internas (`#cardapio`, `#sobre`) ligando o menu ao resto da página
- Media query pra empilhar o layout em telas estreitas

## Como rodar

Só abrir o `index.html` no navegador.
